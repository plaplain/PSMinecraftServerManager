# PowerShell Documentation

This directory contains automatically generated documentation for the PowerShell cmdlets in the PSMinecraftServerManager module.

## Generated Documentation

The documentation is automatically generated from the PowerShell source files in the [src](../src) directory.

## Cmdlets

- [Start-MinecraftServer](Start-MinecraftServer.md)
- [Get-PaperMcDownloadUrl](Get-PaperMcDownloadUrl.md)

## How It Works

This documentation is automatically generated by the GitHub Actions workflow defined in [.github/workflows/generate-powershell-docs.yml](../.github/workflows/generate-powershell-docs.yml).

The workflow runs on:
- Manual trigger
- Push to the main branch
- Every Monday at 2 AM UTC

Each PowerShell file's content is parsed and documentation is generated from the help comments and the actual code.
